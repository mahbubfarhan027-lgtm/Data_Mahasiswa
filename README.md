# Data Mahasiswa

Aplikasi pengelolaan Data Mahasiswa berbasis Java. Projek ini dibuat untuk mengimplementasikan konsep Pemrograman Berbasis Objek (OOP) serta struktur data dalam pengolahan informasi mahasiswa.

## 🚀 Fitur Utama
- Pengelolaan data mahasiswa (Tambah, Edit, Hapus)
- Struktur data yang terorganisir di dalam package `javapkg`
- Tampilan antarmuka yang simpel dan responsif

## 🛠️ Teknologi yang Digunakan
- **Bahasa Pemrograman**: Java
- **IDE**: NetBeans
